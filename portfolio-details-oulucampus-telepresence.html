The work

I developed a robot telepresence simulation using the Oulu campus virtual environment. It supported comparisons between unwound and coupled rotations before moving the research into a physical robot setup.

Project contributions & outcomes

  • Connected Unity and ROS 2 across Windows and Linux using TCP/IP.
  • Integrated DWB local planning and A* path planning for navigation and obstacle avoidance.
  • Supported VR studies and questionnaires about comfort and the remote experience.
