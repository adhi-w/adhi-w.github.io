The work

I designed and implemented a monitoring system that connected multiple clients to a mobile robot through a server. Remote users could control the robot and inspect sensor readings through custom interfaces.

Project contributions & outcomes

  • Implemented client’server communication with Windows sockets and TCP/IP.
  • Connected the server to the robot using wireless serial communication.
  • Displayed heading, acceleration, and temperature data in monitoring interfaces.
